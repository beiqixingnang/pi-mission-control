# 纯插件消息时间与主会话时间线

当前版本2.0.8，2026-10-17。用户明确要求保持插件形式，不修改Pi本身。2.0.7的原生显示补丁已撤回；本机六个运行文件已恢复，并与修改前SHA256逐一核对。

## 用户入口

- `/mission time`或`/mission timeline`打开当前主会话的公开时间线。
- 团队工作台按`t`进入同一时间线；成员对话仍由Enter或`/agents 成员名`打开。
- 时间线支持实时公开增量、历史LF分页、暂停跟随、Enter展开、c复制，m返回Pi原生输入框；Esc返回团队，q退出工作台。
- 原生主对话继续由Pi自己渲染，插件不往每条原生消息上加时间，也不插入时间提示词或额外时间消息。

查看主会话时间需要进入插件查看页。它与原生输入界面分开，保留Pi的编辑、发送、复制、导出和中断行为。未来若Pi公开提供消息渲染元数据接口，可以另行评估原生行内显示；当前版本不通过修改程序或运行时猴子补丁绕过限制。

## 显示规则

使用电脑本地时区；当天显示HH:mm:ss，跨天补MM-DD，跨年补年份。用户消息、助手回复和工具记录使用保存的时间，不按正文猜测，因此相同文字的两条消息仍能有不同时间。助手流式回复保留请求开始时间；工具运行中显示已运行时长，完成后使用Pi记录的durationMs。

有工具结束时间和耗时时，以结束时间减耗时恢复开始点；没有耗时时不把整段模型思考时间算作命令执行。缺少旧时间时显示时间未记录，不用当前时间补历史。时间仅作为标题元数据，c复制仍取原逻辑正文与标题。

## 实现与权限边界

`index.ts`通过Pi公开`ctx.ui.custom`打开MissionPanel，并只向面板提供当前sessionManager.getSessionFile的只读定位函数。不能通过模型参数指定任意日志路径。

`viewer.ts`复用成员查看器的公开消息投影、Markdown/工具底色、时间格式、翻页与复制逻辑，以lead/member scope区分来源。主会话没有成员派工或消息发送动作，m只关闭查看页并返回原生输入。查看不启动模型、不创建任务、不确认交付，也不取消当前运行。

`lead-history.ts`监听Pi公开message与tool事件，复用WorkerPublicStream提取公开文本和工具进度；思考、签名和私有提示不进入显示状态。最多保留16项实时预览，完成后由公开磁盘记录接替，session_start/shutdown清空。只在主时间线打开时请求界面刷新。

历史继续由runtime/transcript.ts反向按字节LF读取：每页40公开记录，单次扫描4MiB、原始记录超过1MiB略过，缓存最多400条且约2MiB。不会把1GB日志整体读成字符串，也不改写它。未写完的尾行等待下次轮询。

主时间线展示当前日志里的公开物理记录，可能包括已离开的分支；它不是压缩/编辑/分支投影后的模型上下文。界面明确标注非模型上下文。临时会话没有磁盘日志时，可以显示当前公开增量，不伪造历史。旧日志读不到更早内容时，Home/PgUp会继续有界扫描。

## 撤回旧补丁与兼容

已经恢复本机Windows的六个Pi运行文件：四个消息/工具组件、interactive-mode，以及实际CLI chunk。全部文件与原始备份哈希一致，旧补丁标记为零；恢复没有修改用户配置或会话。

当前源代码删除了原生装饰器、Symbol桥和AST补丁生成模块；安装或加载插件不会修改Pi文件，也不会改原生组件prototype。旧版实现仍可在Git历史7c59b10中审计，它不代表当前启用方案。

scripts/pi-timestamps.mjs仅保留旧版的status/restore恢复功能，apply明确拒绝。恢复需要本机匹配的备份、安装位置/版本与前后哈希，只会恢复记录中由2.0.7改过的文件；不会安装新补丁，不会随插件加载自动执行。普通使用不需要这个维护脚本。

若曾加载旧补丁，请正常退出Pi，再用pi -r恢复原会话，清除进程内旧代码。此后插件更新按正常/reload流程处理，无需改Pi或新建会话。没有加载旧补丁的Pi只需更新插件。

## 验证

- 本机六个Pi文件恢复后逐一匹配原始SHA256，status为patchedFiles=0、installerAvailable=false。
- 真实Pi离线模型在回复期间打开/mission time，先看到公开文字增量，再看到实际工具返回；私有fixture块不可见，返回原生界面不abort主会话、不创建成员/任务。
- 对原生消息组件、interactive-mode与CLI chunks取前后哈希，查看流程前后完全一致；旧原生渲染桥的全局槽位保持原值。
- 查看页测试覆盖主历史分页、重复正文时间、暂停/恢复跟随、复制排除时间、窄屏、临时会话预览，以及拒绝已撤回的apply命令。
- 预览脚本在未修改的Pi上生成六帧，包括原生主界面、成员对话和纯插件主时间线。PNG是隔离夹具渲染，不是用户桌面截图。
