# 用户移动目录后恢复对话

2026-10-23，插件 2.5.6 → 2.6.0，Pi1.4.0。

用户先退出旧 Pi、关闭占用旧目录的终端，再自己移动或改名项目目录，在新目录运行 `pi --recover-here`。输入名称、旧路径或 ID 搜索，回车将选中主对话恢复到当前目录。`/project restore` 提供同一选择器，既有会话可通过 `/reload` 加载；指定完整会话路径的命令支持未登记自定义位置。没有新增独立插件或修改 Pi 宿主。

启动参数走公开 registerFlag，session_start 在 UI 初始化后经公开用户命令分发进入选择器；普通恢复和 reload 不重复弹出启动选择器。用户在显示了当前目标目录的列表中回车就是绑定授权，不调用主模型或生成授权指令。选择前不会打开旧工作区，所以原目录或旧盘符不存在也可以恢复。

选择器只读默认会话库、当前 session-dir 和已登记自定义会话位置，不递归扫描项目源码或列出运行库内的成员日志。显示名称、旧路径和时间，搜索名称、旧路径或 ID。派生 catalog.sqlite 只存元信息、头部指纹、完整 LF 偏移与恢复关联；不存对话正文。首次逐块扫描每条 LF 记录只保留64 KiB前缀，名称来自 session_info；追加后从最后完整记录继续，源替换/截断则重扫。长工具消息不拼成完整字符串。

准备阶段强制重读所选记录头部，获取旧会话 Store 的独占 owner，直到恢复完成才释放，因此已由 Mission Control 管理、正在被另一个 Pi 使用的对话无法重复接入。无插件账本的旧日志仍按用户已退出原 Pi 的操作前提恢复。正文流式备份及复制，只重写延续会话的新 ID、cwd 和来源；不提前用 SessionManager 载入源和副本，实际选中历史由 Pi 在接入时加载一次。原记录和 journal 保留；后续选择器隐藏已有有效副本的旧来源，显式旧路径跟随已完成恢复链，避免重复克隆当前会话。

现有迁移器扩展 restore 动作，完全不 rename 项目目录。复制任务数据库、成员日志/产物、独立笔记数据库和显式摘要路由/缓存。重建任务产物引用及原项目内部成员路径，外部读写根不变；同时处理归档成员/任务记录。目标、revision、验收及历史正文不改写。工作区和状态目录映射用于旧路径查询及验收实际文件检查，搬回旧名称时不会陷入映射循环；原文件内容变了仍拒绝验收，不用“移动过目录”绕过证据验证。

目标/提醒保持暂停。旧运行或等待任务标为 interrupted/unknown，不认定孤儿进程已停止，不创建新 attempt、不重跑旧命令；用户可在新工作区检查并 reconcile，无需先恢复旧目录。已完成或停止主目标在确认工作区时保持原状态和用量，验收记录不重置。

取消或准备失败只撤销本次新会话/状态/笔记副本，用户已移动的项目目录不回滚。宿主已接管后的失败保留 journal 和恢复文件；现有 project_recover 可完成登记。显式恢复可为重新使用的历史目录创建当前身份，普通隐式身份创建仍拒绝抢占历史别名，其他项目当前根和会话记录保持不变。

验证使用临时 agent 和既有“插件回归测试（WSL）”。SDK 测试覆盖手工移动后旧路径缺失、中文/空格、默认/自定义日志、无原插件账本的 Pi 对话、占用拒绝、未知执行保留、取消、笔记/路由/证据/成员记录、原目录发现、重复绑定、已完成目标确认和文件内容变化拒绝。另用超过64 MiB的单条记录检查元信息扫描与原样复制、缓存追加及列表去重。

真实 TUI 先在原 Pi 进程从安装基线 literal `/reload` 加载候选，保留已有测试。然后用户流程模拟关闭该测试 Pi、手工移动测试目录，在新目录启动 `pi --recover-here`，搜索/选择原测试对话；验证恢复阶段没有任何 fixture 模型请求、原始证据/笔记/摘要模型保留、新进程内 `/reload` 后可继续读取文件。再手工搬回，重复流程，最后更新原专用启动器。完成判定使用持久化 journal、owner 释放和 UI 命令握手，避免把 transient 通知或 session_start 早于编辑器就绪误当成完成。

断线续接时核对了最终代码与 Windows、WSL 完整回归和 TUI 记录；两端实际 CLI 在隔离 agent 下均能通过相对包位置发现 `--recover-here`，没有模型请求。共享设置中的安装路径使用同一个目录入口，避免 Windows 直接使用 WSL 的 `/mnt/c/...` 路径。

完整结果见同目录 receipt。原生 Pi 仍需载入选中历史；列表/复制有界不等于任意大对话接管时常数内存。没有操作用户真实开发对话、结束其进程或移动其项目。
