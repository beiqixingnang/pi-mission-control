# Pi1.4 开发基线与源码更新

日期：2026-10-23。插件 2.5.4 → 2.5.5；宿主基线统一为 Pi1.4.0，停止维护 Pi1.3 的兼容测试。

Windows 与 WSL 已安装的 coding-agent、agent-core、ai、codemode、mcp、telemetry、tui 七个 Pi 包逐项确认为 1.4.0，因此没有重复安装全局宿主或操作正在运行的生产会话。插件升级仍通过原会话 `/reload` 加载；宿主进程本身的升级仍需用户在合适时机退出再 `pi -r`。

四个 Pi peer 范围改为 `^1.4.0`，锁文件中七个 Pi 包均锁为 1.4.0；新引入的上游依赖只有 tui 的 `marked-cjk-friendly@0.1.2`。`typebox@1.3.x` 是独立库版本，与 Pi1.3 无关。验证脚本会拒绝误选 1.3 宿主；CI 的 Windows/Ubuntu、Node24 矩阵仅跑 Pi1.4.0，并验证源码快照和依赖基线。没有为此修改宿主程序或用户配置。

仓库源码更新为官方 `v1.4.0` 标签对应提交 `4a080252f06caf63a525d7873c5d94d3c23887e0`，放在 `vendor/pi-1.4.0/`。旧 `vendor/pi-1.3.0/` 已从当前工作树移除，可经 Git 历史取回。导入 1,987 个文件、25,495,803 字节，保留原 MIT 许可证及上游公开配置、测试资源。没有安装或执行这份参考源码；npm 插件包仍排除整个 vendor。

`vendor/pi-source.json` 保存归档 SHA-256、固定提交和文件树摘要。归档按固定提交下载并逐文件提取；`scripts/check-pi-source.mjs` 只读核对文件数量、正文摘要、源码版本、peer 范围及锁文件。正文摘要仅规范化 UTF-8 文本 CRLF/LF，以兼容上游 Windows 脚本检出规则。校验标识本次归档，不声明官方发布签名认证。

旧研究报告保留其基准日期与版本事实，27 个原源码链接改指向本仓库固定历史提交 `a796417cfd213d22e11852be273779bdceb78d15`，保持旧文件和行号可追溯；没有把原研究里的 1.3 结论直接改称为 1.4 实测。当前 README、贡献指南、产品/技术规格和归属说明已更新。

验证仅使用临时 agent 配置和“插件回归测试（WSL）”。完整 Windows/WSL 回归、严格类型、入口加载、干净依赖安装、打包排除检查及原进程 TUI `/reload` 的结果见同目录 `PI14-BASELINE-2026-10-23.receipt.json`。TUI 同时保留故障恢复、目标证据、笔记、自然语言改名往返等既有检查；没有向真实模型发送测试请求。
