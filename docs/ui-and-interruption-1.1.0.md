# 界面与全局停止（1.1.0）

保持 Pi 原版与插件运行方式，不改 CLI、模型接口或 ccSwitch 对接。

## 停止和输入

- **Esc**：只要主请求或成员正在运行，即全局停止主请求、团队当前/排队任务与普通子智能体；暂停 Goal、关闭监督器并取消插件重试退避，防止停止后被结果重新唤醒。成员身份与历史保留；已经发生的文件修改不会撤销。
- **`/stop`**：相同的全局停止命令，也可通过 RPC/SDK 发送；没有使用内部 monkey patch。
- 停止尚未完全收束时新输入的普通消息会暂存，等主回合与成员取消完成后重新发送，不放进正在取消的旧回合队列。
- **普通 Enter**：保留 Pi 原生的 `steer`（插话）语义，在当前响应/工具的安全交接点优先处理，界面增加中文提示。不会把它改成任务结束后的 `followUp`；也不承诺立即抢断一条已经发送给上游的响应。
- **Ctrl+Q（Windows/WSL）/Alt+Enter（其他终端）**：Pi 原生的显式追加消息操作。
- 完全空闲时 Esc 留给 Pi 的菜单/编辑器。存在执行任务时，Esc 优先全局停止，即使正在查看成员；无执行任务时，查看器中的 Esc 只返回。

取消主请求通过 Pi 的标准 abort/AbortSignal。团队成员优先等待 RPC abort，2 秒内无法结束会关闭该成员子进程并保留持久定义。普通子智能体发送终止信号，必要时在约 1.5 秒后强制结束其 Pi 子进程。这里不撤销上游已收到的请求，也不回滚已完成的文件操作。

## 消息时间

成员列表区分：

- `消息 HH:mm:ss`：最近可见文本的时间，工具执行/重绘不会刷新它。
- `活动 HH:mm:ss`：最近程序事件的时间。
- 主 AI 侧栏还显示 `主AI停稳`，来自最终 `agent_settled`；低层 agent_end 仍可能继续重试，因此不当作停稳。

日期不同会显示月/日。主 AI 从主会话恢复最后消息，持久成员从成员定义恢复最后文本时间；临时子智能体的完成记录会短暂显示，历史缓存在当前主进程内保留（有条数/长度上限）。历史缓存不包含 thinking 正文、签名或系统提示。

## 自动布局

- 默认 `auto`：全屏 TUI 至少 **140 列、24 行**时，左侧约 2/3 保留 Pi 原生聊天/输入，右侧约 1/3 显示控制区。
- 右侧上半显示目标/验收条件、主 AI 时间、监督器开关和下次检查；下半显示成员状态、消息时间和实时预览。
- 小窗口回到最多 3 行紧凑显示。改变窗口尺寸不清空输入草稿或聊天历史。
- `regular` TUI 或布局 API 不匹配时回退紧凑视图。

```text
/agents auto
/agents compact
/agents wide
/agents off
/agents on
```

`wide` 的最小宽度为 120 列。右栏不覆盖主对话，而是使用 Pi 的横向布局。Pi 1.2.0 没有读取当前布局根的公开 getter，因此适配器在检查结构后读取该版本 renderer 的现有 layoutRoot，用公开 setLayoutRoot 包装和恢复它；这个兼容点依赖 Pi 版本，升级后必须重新测试。无法识别原布局时不修改它。

## 成员对话查看

- `Alt+J` 循环选择成员，`Alt+O` 打开查看器。
- 或输入 `/agents view cpu-builder`。
- 查看器支持 ↑↓、PgUp/PgDn、End 跟随末尾，Esc 返回。
- 查看模式只读，不切换主 Pi 会话，不发送模型消息，不修改主输入框。主 AI 和成员可继续工作。
- 持久团队通过 RPC 读取可见历史；普通子智能体查看本轮捕获的可见消息、工具调用及结果。默认保留最近 200 项，每项最多 12000 字符；实时预览最多 1000 字符。

当前提供键盘导航和命令入口，没有新增鼠标点击成员发送指令的功能。真实 Windows Terminal 的字体、鼠标、输入法和主题效果仍需用户现场观察；自动化测试验证了渲染布局、宽字符边界、只读查看和返回行为。

Windows / Node v24.16.0 与 Debian WSL / Node v22.23.3、Pi 1.2.0：九个入口加载成功，**91/91 测试通过**。

测试使用独立临时配置、离线 provider fixture，不改当前硬件团队/项目，不访问真实模型 API：

```bash
npm run check
npm test
```

新增覆盖包括 Esc 监听、停止过程暂存新输入、队列任务取消、迟到唤醒抑制、真实主请求取消后新指令可执行、真实普通子进程退出、团队身份仍可用，以及 Pi fullscreen renderer 的宽窄切换、原布局恢复、历史只显示可见内容和消息时间不被活动刷新。
